# Нота (Noto)

Минималистичная цифровая тетрадь для рукописных заметок, лекций, схем и рисования. Работает полностью офлайн в браузере и как настольное приложение Windows.

## Возможности

- **Инструменты письма**: ручка, карандаш, маркер и ластик с плавными кривыми Безье.
- **Типы листов**: клетка, линейка, точки, чистый лист; настраиваемый цвет бумаги и обложки.
- **Умные фигуры**: прямые и пунктирные линии, стрелки, прямоугольники, круги, треугольники и звёзды. При ведении по клеткам линии автоматически выравниваются строго по сетке.
- **Интерфейс**: светлая и тёмная темы, управление масштабом (пресеты, 70% по умолчанию, вписывание по ширине).
- **Экспорт и сохранение**: экспорт в PDF, PNG и векторный проект `.noto`. Автоматическое локальное сохранение в IndexedDB.

## Скачать

Готовые исполняемые файлы для Windows (`.exe` инсталлятор и портативная версия) доступны во вкладке **[Releases](../../releases)**.

## Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск режима разработки
npm run dev

# Сборка веб-версии
npm run build

# Сборка исполняемого файла Windows (.exe)
npm run build:exe
```
